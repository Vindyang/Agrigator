This is a [Next.js](https://nextjs.org) project using [shadcn/ui](https://ui.shadcn.com) with Tailwind CSS v4.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Open [http://localhost:3000](http://localhost:3000) in your browser.

The starter page is in `src/app/page.tsx`.

## shadcn/ui

The project was initialized with shadcn and already includes:

- `button`
- `card`
- `badge`
- `input`

Add more components with:

```bash
npx shadcn@latest add dialog table form
```
